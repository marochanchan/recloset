  - 署名付き URL の期限を時間単位でそろえて、同じ URL を使い回し、ブラウザのキャッシュを効かせる
  - 一覧は thumb だけにし、display と analysis は必要なときだけ出す
  - 動画は先読みしない（`preload="none"`、最初は静止画だけ）。先読みも配信の分数に数えられるため
  - 配信量を定期的に確かめ（Cloudflare の利用量の API など）、決めた量を超えたらアプリ側で新しいアップロードや動画の再生を止める非常用のスイッチ
