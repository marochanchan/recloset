## Supabase の利用量（Egress）（2026-10-27 確認。10月末の予定は変えない）

- 請求期間 10/15〜11/15、Free プラン。10/27 時点：Egress 2.244/5GB、Cached Egress 0.759/5GB、Storage 0.17/1GB、Database 0.028/0.5GB。前の期間の Egress 超過の猶予は 11/11 まで
- 今のペース（1日約0.19GB）が続くと、11/10 ごろに 5GB を超える見込み。もう一度超えると猶予なしで制限される（API がすべて 402、読み取り専用、停止のどれか）。Pro にすればすぐ解除される
- [ ] 11/1 と 11/5 に利用量を確かめ、Pro にするか決める（ユーザー。勝手に有料プランへ変えない）。目安：11/3 の時点で Egress が 3.5GB を超えていたら、11/10 の本番での通しの確認より前に決める
- [ ] Egress が増える原因を確かめる（Usage の日ごとのサービス別の内訳、ログで多く呼ばれているパス）。コードから考えられる原因：服の写真の署名付き URL が少なくとも15分ごとに変わる（サーバーが切り替わるとさらに頻繁）ため、Vercel の画像の最適化とブラウザのキャッシュが効かず、元の写真（長辺1600px）を Supabase から取り直している
- [ ] キャッシュの改善を試し、効果を確かめる（11月に入ってから）。候補：署名付き URL を決まった長めの区切りで使い回す、一覧用の小さな写真を作る、服の写真も Cloudflare Images に移す
