# 音声 × 画像認識 スマートミラー

## AI Wardrobe Mirror — スマートフォン中心の衣服管理・撮影システム

**コンセプト企画書｜Hackathon Prototype 改訂版**

### 1. コンセプト

**「鏡で着画を撮る。スマホで服を撮る。AIが自動的に整理する。」**

スマートミラーとスマートフォンを組み合わせ、日々の服装や所有する衣服を写真で記録・管理するシステム。

鏡は、音声・ジェスチャーによるハンズフリー撮影を担当する。

スマートフォンは、平置き写真の撮影、鏡からの着画の受信、衣服の識別、写真の自動紐付け、クラウド同期を担当する。

将来的には、蓄積された衣服・着画の情報を利用したAIファッションアシスタントへ発展させる。

### 2. システム全体構成

**基本方針：スマホアプリをハブとし、鏡からクラウドへは直接接続しない。**

**経路A：平置き写真**

スマホカメラ → スマホアプリ → 衣服の認識・登録 → クラウド

**経路B：着画**

鏡デバイス（カメラ・マイク） → Wi-Fi → スマホアプリ → 衣服との自動紐付け → クラウド

**スマホアプリの役割**

- 平置き写真の撮影
- 着画の受信とプレビュー
- AIによる衣服の画像認識
- 平置き写真と着画の自動紐付け
- 衣服・コーディネートのグラフ管理
- ローカルキャッシュ管理
- クラウドへの非同期アップロード
- 写真の検索・閲覧・修正

鏡側にはクラウド接続機能を持たせず、撮影とスマートフォンへの画像転送に専念させる。

### 3. 撮影のユーザー体験

#### A. 鏡による着画撮影

1. 鏡の前に人が立つ。
2. 一定時間（例：3秒）経過するとアシスタントが起動。
3. 「写真を撮りますか？」と音声で案内。
4. 「写真撮って」と話す、または手のひらを見せる。
5. 5秒のカウントダウン後に全身撮影。
6. 写真を鏡デバイス内に一時保存。
7. Wi-Fi経由でスマートフォンへ画像を転送。
8. スマホアプリが写真を解析し、衣服との紐付け候補を生成。

撮影自体はスマートフォンが手元になくても行える構成を目指す。未転送の写真は鏡側に保持し、接続時に転送する。

#### B. スマートフォンによる平置き撮影

1. 服を床や机に置く。
2. スマホアプリから撮影。
3. AIが服の種類・色・特徴を抽出。
4. 既存の衣服データと照合。
5. 新しい衣服なら登録、既存の衣服なら写真を追加。
6. 過去の着画とも照合し、関連付け候補を表示。

### 4. AIによる衣服・着画の自動紐付け

**スマホアプリ内のアシスタントが、二つの撮影経路を統合する。**

例えば以下の写真がある。

- 平置き写真A：白いシャツ
- 平置き写真B：青いジーンズ
- 着画C：白いシャツと青いジーンズを着た全身写真

AIは着画Cから服の特徴を抽出し、既に登録された衣服との類似度を計算する。

その結果、着画Cと衣服A・Bを自動的に紐付ける候補を生成する。

**主な処理**

- 衣服の検出・領域抽出
- 服の種類、色、模様などの特徴抽出
- 画像Embeddingによる類似画像検索
- 撮影日時や履歴を利用した候補の絞り込み
- 信頼度の評価
- ユーザーによる確認・修正

※ 平置きと着用状態では服の形状や見え方が異なるため、完全自動判定を前提とせず、候補の提示と簡単な修正操作を基本とする。

### 5. グラフ型データモデル

衣服管理を単純な写真アルバムではなく、**衣服・写真・コーディネート・撮影履歴の関係を持ったグラフ**として扱う。

**管理する主なノード**

| ノード          | 内容          |
| ------------ | ----------- |
| Garment      | 実物の衣服1点     |
| FlatLayPhoto | 平置き写真       |
| WearingPhoto | 着画・全身写真     |
| Outfit       | 衣服の組み合わせ    |
| Session      | 撮影日時・撮影イベント |

**主な関係（エッジ）**

| 関係                     | 意味                 |
| ---------------------- | ------------------ |
| Garment → FlatLayPhoto | この衣服の平置き写真         |
| Outfit → Garment       | このコーディネートを構成する衣服   |
| WearingPhoto → Outfit  | この着画に写っているコーディネート  |
| Session → WearingPhoto | この撮影時に生成された写真      |
| WearingPhoto → Garment | AIが推定した着用衣服（候補・確定） |

例えば、同じ白いシャツが複数のコーディネートに登場しても、Garmentは一つのノードとして管理する。

将来的には「このシャツを着た写真を全部見せて」「先月のコーディネートと比較して」といった検索が可能になる。

**初期段階ではグラフデータベースの導入は必須ではない。** SQLiteやPostgreSQLのノード・関係テーブルで開始し、必要に応じてGraph DBへ発展させる。

### 6. デバイス間通信とクラウド同期

#### 鏡 → スマートフォン

**初期推奨：Wi-Fiによるローカル通信**

| 方式            | 用途・評価                   |
| ------------- | ----------------------- |
| Wi-Fi（同一LAN）  | 高解像度写真の転送に適する。初期試作の第一候補 |
| Bluetooth LE  | デバイス検出・ペアリング・少量の制御情報向け  |
| Wi-Fi Direct等 | 家庭内LANに依存しない接続。後の検討対象   |

初期実装では、鏡側に小さなHTTPサーバーを設け、スマホアプリが写真を取得するPull方式でもよい。

#### スマートフォン → クラウド

- オリジナル画像はスマートフォン側で受信・管理。
- サムネイルとメタデータを優先して同期。
- オリジナル画像のクラウド保存は任意設定。
- ネットワーク切断時は同期キューに保持。
- アプリ起動時など、転送可能なタイミングで再送。

初期段階ではアプリを開いている間の確実な転送・同期を優先し、OSによるバックグラウンド実行制限への対応は後の段階とする。

#### 鏡側のデータ保存

鏡デバイスのローカルストレージ（将来的にはSSD）は、未転送画像の一時保管と転送失敗時の再試行に使用する。

スマホでの受信確認後に削除するか、一定期間保持するかは設定可能にする。

### 7. 開発フェーズ

| フェーズ    | 検証内容                      | ハードウェア       |
| ------- | ------------------------- | ------------ |
| Phase 0 | 人物検知、音声、ジェスチャー、写真撮影       | ノートPC＋Webカメラ |
| Phase 1 | スマホへの画像転送、平置き撮影           | ノートPC＋スマホ    |
| Phase 2 | 衣服認識と写真の自動紐付け             | 同上           |
| Phase 3 | グラフ管理、クラウド同期              | 同上           |
| Phase 4 | ハーフミラー・Raspberry Piへの組み込み | 専用ミラー試作      |
| Phase 5 | AIコーディネート相談、商品化検討         | 製品化候補        |

**コンセプト開発段階ではノートPC＋Webカメラ＋スマートフォンで十分。**

まずは鏡そのものを製作せず、撮影体験・デバイス連携・衣服の自動紐付けというソフトウェアの価値を検証する。

### 8. ハッカソンのMVP

**優先順位1：ハンズフリーで撮影する**

- 人物検知によるアシスタント起動
- 音声・手のひらによる撮影指示
- 5秒タイマー撮影
- ローカル画像保存

**優先順位2：スマートフォンとつなぐ**

- スマホから鏡デバイスへ接続
- Wi-Fiで着画を転送
- スマホで平置き写真を撮影
- 両方の写真を一覧表示

**優先順位3：AIで衣服を紐付ける**

- 平置き写真から衣服の特徴を抽出
- 着画との類似度を計算
- 紐付け候補を提示
- 衣服・写真・コーディネートの関係を保存

クラウド同期と高度なファッション相談は追加機能とする。

### 9. 将来構想

スマートミラーから蓄積した着画と、スマートフォンで登録した衣服のデータを使い、AIアシスタントを発展させる。

- 「この白いシャツを最後に着たのはいつ？」
- 「このジーンズに合う服は？」
- 「先週の服装を見せて」
- 「今日の天気なら何を着る？」
- 「最近着ていない服は？」
- 「似たような服を何着持っている？」

これらの質問には、服装の画像だけでなく、衣服・撮影・コーディネート間の関係情報を活用する。

### 10. LTのメッセージ

**「AIミラーの頭脳は、実は鏡の中ではなくスマートフォンにある。」**

鏡は自然なハンズフリー撮影のためのデバイス。

スマホは普段の服の撮影と、AIによる衣服管理の中心。

そしてクラウドは、写真や衣服の履歴を蓄積・検索するための基盤。

最終的に目指すのは、**写真を撮るたびに、自分のワードローブが自動的につながっていく仕組み。**
